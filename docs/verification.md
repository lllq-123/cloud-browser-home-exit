## 本次整理没有做的

- **没有在一台全新服务器上从零装一遍。** 第 2、3 步的安装命令是按我们当初的做法和官方文档写的。Playwright 装 Chromium 的具体命令我们当时没留记录；教程里钉的 Playwright 1.59.1 是按官方版本表反查的，它装出来的正是我们家在用的 `chromium-1217`（147.0.7727.15），连带的 `chromium_headless_shell-1217`、`ffmpeg-1011` 也和我们服务器上的一样（2026-10-28 用 `--dry-run` 核对过下载地址还能下）。
- 扫码登录那一节，截图发给主人的命令是按 OpenCLI 的 `browser screenshot` 写的；我们当时是从页面里取的二维码，具体怎么取没留记录。
- 第 1 步里往手机放文件的那组命令（电脑上 `adb push`、手机 root shell 里解压、复制、改权限），是按我们家手机上的最终状态整理的；我们当时是用自己的工具一条条写进去的，没有用 adb 从头跑过。
- 没有验证「扫码登创作中心会不会顺便登上主站」。
- 手机那一套只在一台 root 过的一加 8T（Android 14、Magisk 30）上跑过。
- 这些命令只在 OpenCLI 1.8.7 上跑过，没在 2.x 上试。
- 没有发测试评论、没有改任何我们家正在跑的东西。

## 公开版和我们家原件的差别

- 手机脚本把域名、IP 抽成了两个变量，nginx 路径改成了 `/home-exit/`，其余一样。
- PAC 只保留了小红书相关的两条；我们家的还有几个别的站的域名。
- nginx 路径从我们家的私有路径改成了 `/home-exit/`。
- 入口脚本里本机路径改成了变量；13 条命令的注释和提示文案去掉了家里路径和人名，加了许可证头，执行流程没改（见 `opencli-xiaohongshu/NOTICE.md`）。`install.sh` 多复制了 `LICENSE` 和 `NOTICE.md`，装好的目录里也带着来源说明。
- 看门狗、凌晨整理脚本、我们家的 App 没有公开。

## 已知边界

- 手机不在线时主站打不开，故意不回退到海外 IP。
- 评论可能被送审、帖子可能被藏，原因没有一件被证实；本教程不提供任何「一定能发出去」的保证。
- 小红书官方不允许 AI 托管账号，照做有被限流、封号的风险。
