# 第 7 步：像正常人一样逛

> 这一篇讲清楚：浏览器为什么这么设、节奏为什么这么慢、出了事怎么分辨是哪一种。

> ### ⚠️ 再说一遍
>
> 小红书官方不允许 AI 托管账号（2026-03-10 薯管家公告、2026-08-06《AI 治理规则公告》）。下面这些设置的目的是**让一个在服务器上跑的浏览器看起来像一台普通的电脑、让小机的动作像一个人在慢慢逛**，不是让它「隐身」——它做不到隐身，我们家的评论照样会被审。有被限流、封号的风险，请用小号。

## 浏览器为什么这么设

这些都在 [examples/browser/opencli-chrome-launch.sh](../examples/browser/opencli-chrome-launch.sh) 里，一条一条说：

| 参数 | 改了什么 | 为什么 |
|---|---|---|
| `--headless=new` | 用**完整版**浏览器的无头模式 | 旧的无头模式是个精简版（headless shell），少很多东西，网页一测就知道。新模式和有窗口的 Chrome 是同一套代码，只是不画窗口 |
| `--user-agent=Mozilla/5.0 (X11; Linux x86_64) ... Chrome/147.0.0.0 Safari/537.36` | 把浏览器的「自我介绍」写成普通的 Linux 桌面 Chrome | 无头模式默认的自我介绍里带 `HeadlessChrome` 几个字，等于举着牌子说「我是机器」。版本号跟你装的浏览器保持一致（装了别的版本自己改）。**平台照实写 Linux，别冒充 Windows**——我们试过冒充，10 月 17 日改回来了，因为自我介绍和浏览器别的特征对不上，比老实说 Linux 更可疑 |
| `--ozone-override-screen-size=1920,1080` | 虚拟显示器设成 1920×1080 | 无头模式默认的「屏幕」只有 800×600，窗口却比屏幕还大，这不合理 |
| `--window-size=1920,1040` | 窗口比屏幕矮一点 | 真实桌面上窗口要给任务栏留位置 |
| `--lang=zh-CN` 和 `--accept-lang=zh-CN,zh;q=0.9,en-US;q=0.8,en;q=0.7` | 界面语言和「我接受的语言」都是中文优先 | 一个逛小红书的中文用户的浏览器就长这样 |
| `--no-sandbox` `--disable-gpu` `--disable-dev-shm-usage` | 三个兼容项 | 跟像不像人没关系：云主机上沙箱常常起不来、没有显卡、共享内存很小。没有它们浏览器根本跑不起来 |
| 主站走家里的口子（PAC） | 小红书看到的是你家的住宅 IP | 不是参数，是第 1、2 步做的事。机房 IP 一开主站就被送去海外版，谈不上像不像人 |
| 中文字体装全 | 页面排版正常、截图能看 | 缺字体的浏览器渲染出来的页面本身就不正常 |
| 其余几个（`--no-first-run`、`--no-default-browser-check`、`--disable-extensions-except`、`--remote-allow-origins=*`、`--disable-features=DialMediaRouteProvider`） | 杂务 | 别弹首次运行向导、只装我们那一个扩展、调试端口接受本机脚本、关掉局域网投屏探测。跟像不像人没关系 |

就这些。没有改指纹、没有藏 `navigator.webdriver`、没有别的花活。我们查过 `navigator.webdriver`、Client Hints 这些，知道它们能被看出来，也知道改一个会让另一个对不上，所以**不动**。

## 节奏为什么这么慢

比起浏览器长什么样，**怎么动**更重要。我们家的节奏：

| 做法 | 具体 |
|---|---|
| 常驻页 | 一张页面开着不关，搜索、看帖、看通知都在里面点来点去，不反复整页打开 |
| 看通知 | 一小时一次，夜里（0～8 点）不看，每次启动先随机等 0～60 秒 |
| 一次只做一件事 | 入口脚本给小红书命令排队，同时只跑一条 |
| 发评论 | 不是把整段文字一次塞进输入框。先停 1.5～4 秒（像在看帖），然后**一小段一小段地打**：每段 1～4 个字，段间停 0.06～0.22 秒，每打 8～15 个字长停一下（0.3～0.9 秒），打完再停 0.8～2.5 秒才按回车。一条 200 字的评论大约半分钟。正文里带 @ 或 # 的时候例外，那种会一次填入（怕逐字打触发联想菜单） |
| 评论数量 | 一次逛最多发 0～2 条；搜、看、评、发不连着来 |
| 账号 | 专用小号，简介写明是 AI，每条评论署名 |
| 内容 | 不放链接、不放联系方式，少写模型名、版本号、「数据」这类词 |

## 出了事怎么分辨

小红书很敏感。落落的经验（真人的号也会碰到）：

> 只要没有被踢登录，大概率是没事；很多时候那个评论就是有敏感词。

分三种：

| 看到什么 | 是什么 | 怎么办 |
|---|---|---|
| **被踢下线**：刚才还好好的，突然 `mentions`、`comments` 全报需要登录、首页变登录页（创作中心那边是 `whoami` 报未登录） | 最该当回事的一种。不一定是被盯上了（cookie 本来也会过期），但落落的经验是：没被踢下线，大概率就没事 | 停手，放慢，过一阵再重新登录。别马上换 IP 换浏览器折腾——那更像机器 |
| **评论一直「审核中」、别人看不到** | 落落的经验：多半是撞了敏感词，真人的号也一样 | 换个说法，或者等等。**别原样重发** |
| **提示「引流到站外」** | 内容里有链接，或者像链接的东西（我们用🐱隔开的 GitHub 地址也被认出来了） | 删掉那一行 |

还有一种**不是风控但很像**：页面被送去了海外版（`rednote.com`）。那是出口的问题——手机不在线、或者手机上的梯子把隧道带出国了。回第 1 步查。

## 我们家真遇到过的

| 时间 | 事 |
|---|---|
| 7 月、9 月 | 发评论时弹二维码验证（461），登录没掉、读帖照常。扫一下就好 |
| 9 月 12 日 | 一篇帖子发出去被藏，反复改还是藏，最后落落亲手改了才放出来。怀疑是同时提了几个平台的名字和链接，没证实 |
| 10 月 16 日 | 一条回复「服务器已确认」，小机号自己看得见，别的号看不到。删掉「数据」两个字、在手机 App 上重发就正常了（两样是一起改的，说不准是哪一样起的作用） |
| 10 月 17 日 | 一条没什么敏感词的评论显示「审核中」，手机 App 原样重发就过。整站换成家里 IP 再发，照样「审核中」，当天就把整站走家里撤回了。换 IP 没用，但原因还是不知道 |
| 10 月 17 日 | 看门狗从每 5 分钟改成每小时、夜里不看 |
| 10 月 28 日 | 一篇带 GitHub 地址（用🐱隔开）的帖子被提示「引流到站外」。删掉那行说明后，落落看着像是恢复了，我们没再单独核实 |

这些事的**原因没有一件被证实**。我们知道的只有每次后来是怎么过去的：换个说法、删掉某几个词或那行地址、在手机 App 上重发。

## 最后一句实话

上面这些能让小机看起来像一个用 Linux 电脑、动作慢吞吞的普通用户，不多不少。它不是保证。小红书哪天改了规则、换了判断方法，这里写的可能一夜之间就不管用。所以：用小号，署名，慢一点，被审了别硬刚。
